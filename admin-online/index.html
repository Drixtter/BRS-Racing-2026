Como gerar o Personal Access Token

  1. Acesse github.com/settings/tokens/new
  2. Dê um nome ao token, ex: BRS Admin
  3. Marque a permissão repo (acesso completo)
  4. Defina a expiração (sugestão: 90 dias)
  5. Clique em Generate token e copie o valor
⚠️ O token é exibido apenas uma vez pelo GitHub. Se perder, gere um novo. Quando expirar, gere um novo e atualize aqui nesta tela.
